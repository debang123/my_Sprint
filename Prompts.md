
# AI Prompts Documentation – Prodesk IT Landing Page

## Project Information
- **Project Name:** Prodesk IT – Landing Page
- **Sprint:** Sprint 1
- **Purpose:** Build a professional, responsive landing page for a digital marketing company.
- **Technologies:** HTML5, Tailwind CSS, CSS, JavaScript
- **Deployment:** Vercel

---

## Prompt 1: Responsive Design

**Prompt:**

Review the landing page and improve its responsiveness. Use Tailwind CSS responsive utilities to ensure that the navbar, hero section, About section, and Services cards work properly on desktop, tablet, and mobile screens. Prevent horizontal scrolling and maintain consistent spacing.

**Purpose:** To improve the user experience across devices.

## Prompt 2: JavaScript Functionality

**Prompt:**

Help me implement JavaScript functionality for the landing page. Make the mobile hamburger menu interactive and ensure the navigation works correctly. Keep the JavaScript code clean and avoid duplicate event listeners.

**Purpose:** To add interactive functionality.

## Prompt 3: UI Improvements

**Prompt:**

Review the landing page design and suggest improvements to make it look more modern and professional. Focus on typography, spacing, colors, button styles, card layouts, hover effects, and overall visual consistency.

**Purpose:** To improve the overall user interface.

## Prompt 4: Testing and Debugging

**Prompt:**

Review my HTML, CSS, Tailwind CSS, and JavaScript code for errors. Identify issues affecting responsiveness, navigation, layout alignment, and functionality. Suggest fixes without unnecessarily changing the existing design.

**Purpose:** To identify and fix development issues.
